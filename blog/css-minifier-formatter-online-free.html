Frequently Asked Questions

What is a CSS minifier?
A CSS minifier removes unnecessary whitespace, comments, and redundant characters from CSS code to reduce file size for faster page loading.

Is online CSS formatting private?
Yes — browser-based CSS tools process everything locally. Your code never leaves your computer. No upload, no server, no tracking.

What's the difference between format and minify?
Formatting beautifies CSS with proper indentation for readability. Minifying removes all whitespace and comments to reduce file size for production.
